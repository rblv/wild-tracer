# Решение проблем

## Установщик блокируется Windows

Скачивайте установщик только с официальной страницы [Releases](https://github.com/rblv/wild-tracer/releases). Ранние unsigned builds могут показывать предупреждения SmartScreen.

## Приложение не собирает данные

Проверьте, что:

- Токен введен корректно;
- Токен скопирован из реального браузера;
- сеть доступна;
- не истек срок действия токена.

## Достигнут лимит товаров Demo

Wild Tracer Demo поддерживает до 20 активных товаров. Удалите товары, которые больше не отслеживаются, перед добавлением новых.

## Обратная связь

Создайте публичный issue в:

https://github.com/rblv/wild-tracer-feedback

Не прикладывайте tokens, cookies, приватные данные аккаунта, локальные базы данных или логи с чувствительными данными.
