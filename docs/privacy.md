# Приватность

Wild Tracer Demo работает по local-first модели.

## Локальные данные

Приложение хранит отслеживаемые товары, snapshots, проверки позиций по ключевым словам, настройки, логи и локальные базы данных на вашем компьютере.

Не публикуйте локальные базы данных или логи, пока не проверите их и не удалите чувствительные данные.

## Wildberries token

Wild Tracer Demo использует вручную введенный браузерный токен для сбора данных.

Никогда не публикуйте токены, куки, данные аккаунта, скриншоты с приватной информацией или логи с чувствительными данными в GitHub issues.

## Обратная связь

Отзыв отправляется только когда вы явно отправляете его из приложения или вручную создаете публичный issue.

Публичный репозиторий обратной связи предназначен только для очищенных обращений. Не публикуйте там чувствительные данные.
