# Ограничения Wild Tracer Demo

Wild Tracer Demo - публичная product-only demo.

Текущие ограничения:

- до 20 активных товаров;
- до 5 ключевых слов позиции на товар;
- одиночное ручное добавление товара;
- ручной сбор данных;
- ручная проверка позиций по ключевым словам;
- один вручную введенный токен;
- безопасный экспорт базы данных.

В Demo не входят:

- массовый импорт товаров;
- планировщик/расписание;
- импорт товаров продавца;
- импорт товаров бренда;
- регистрация, оплата, лицензирование, облачная синхронизация.
