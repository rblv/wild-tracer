# Установка Wild Tracer Demo

## Требования

- Windows 10 или Windows 11.
- x64 CPU.
- Доступ к интернету для запросов к Wildberries API.
- Токен из браузера, введенный вручную, для сбора данных по товарам.

## Скачать и установить

1. Откройте страницу [Releases](https://github.com/rblv/wild-tracer/releases).
2. Скачайте последний `Wild Tracer Demo-<version>-win-x64.exe`.
3. При необходимости скачайте соответствующий `.sha256` файл и проверьте checksum.
4. Запустите установщик.
5. Откройте **Wild Tracer Demo**.

## Windows SmartScreen

Ранние публичные сборки могут показывать предупреждение `Unknown Publisher` или предупреждение SmartScreen, пока установщик не подписан code signing certificate и не набрал репутацию. Скачивайте установщики только из этого репозитория.

## Где хранятся данные

Wild Tracer Demo хранит локальные данные приложения в профиле пользователя Windows. Данные не смешиваются автоматически с будущими редакциями Products или Market.

Demo поддерживает безопасный экспорт базы данных для бэкапа и диагностики.
